Animaciones Flip - Transiciones entre Paneles

Cada fase del juego "gira" como una carta

Concepto de Flip

Cuando cambias de fase (ej: Bidding → Playing), la pantalla completa gira como una carta sobre su eje horizontal.

CSS para Flip

/* Contenedor con perspective */
.flip-container {
  perspective: 1000px;
}

/* Panel que gira */
.flip-panel {
  transform-style: preserve-3d;
  transition: transform 0.6s ease-in-out;
}

/* Girar 180° */
.flip-panel.flipped {
  transform: rotateY(180deg);
}

/* Frente y dorso */
.flip-front, .flip-back {
  backface-visibility: hidden;
  position: absolute;
  width: 100%;
  height: 100%;
}

.flip-back {
  transform: rotateY(180deg);
}
